- Keep the uploaded certificate editor in `src/features/certmaker` and render it at `/` through TanStack Router; this preserves the editor while retaining the hosting framework.
- Keep certificate analysis, rendering, exports, and saved device designs browser-side; uploaded app privacy and offline-style workflows do not need a backend.
- Keep uploaded UI styling in semantic global tokens and the certificate Button variant; this preserves its design through Tailwind v4.
- Preview renders must commit offscreen frames only while their effect is live, clear pending state on failure, and retain the clone overlay during redraws; this prevents stale frames without interrupting pointer capture or text editing.
- Map clone pointer coordinates against the canvas content area with independent horizontal and vertical scales, and clamp field geometry at the update boundary; this keeps panel, drag and export coordinates consistent.
- CSV substitution preserves unknown tokens but replaces explicitly empty cells with empty text; this distinguishes missing columns from intentional blank field values.
- Keep local field commands device-only and allowlisted. Optional AI instruction planning in clone-ai-edit.ts may send instruction text and editable field text/styles only with its own explicit provider consent; never send template images or CSV rows through this editing path. Review validated plans, or apply automatically only when the user enables it and layout checks have no warnings, through the same local command engine; invalidate reviews after template or field changes to avoid stale edits, and keep instruction editing separate from detection requests.
- Fit clone replacement text with browser text metrics in `clone-text-layout.ts` and clip it consistently for every erase mode; preview and exports share the same painter to prevent text spilling into neighbouring fields.
- Clone imports must use the isolated browser-only text detection module, never the reference style analyser; render the original first and change only explicit text rectangles to preserve locked artwork.
- Keep clone source images session-only like reference images and preserve source aspect ratios in preview and exports; this avoids storage quota failures and stretching the original.
- Clone Mode exports at the original's own pixel width (`exportWidth`) and sizes PDF pages from the source (`pageSize`); never resample or stretch the artwork. Keep text-field detection pure in `clone-detect.ts` and box geometry in `clone-geometry.ts` so both stay unit-tested.
- Optional AI text detection in Clone Mode (`clone-ai.ts`, providers: Google Gemini and Groq) and optional AI instruction planning are the features that send data off the device; both use bring-your-own-key, session-only keys (never in the repo, localStorage or a URL; sent in a header only), explicit consent, and never send CSV row data. Detection sends only the template image plus CSV column NAMES and only reads/locates text; it must not choose colours or edit artwork. Instruction planning sends only the consented instruction and editable field context and may plan allowlisted text/typography edits; certificate artwork remains locked. Validate every model answer strictly; do not send deprecated sampling parameters. Overload (HTTP 5xx), timeouts and short rate limits are retried with backoff and then fall back to another model; key, model, format and quota errors are never retried. Model IDs change often, so keep the model field free-text and re-check the provider docs before changing defaults.
- Clone Mode erases old text with "smart erase" (`clone-erase.ts`), not a flat rectangle: it removes only the old writing's own pixels, protects printed dotted leader lines, long rules and known static text (`clone.suggestions`), and fills from the surrounding paper. It only ever changes pixels inside a field's own analysis window, and only for fields with explicit text or typography edits. Keep the analysis pure (raw pixel arrays) and tested; never widen it to touch pixels outside the window. "Flat patch" and "Don't erase" remain as explicit options.

- The production editing API lives in `lib/editing`: AIEditingEngine, SelectionManager, StyleMatchEngine, CommandParser, EditHistoryManager, PreviewRenderer and LayerInspector. New command paths must remain selection-scoped, schema-validated and atomic. Every command change is previewed and explicitly accepted; no automatic application in this UI.
- Enforce locks and non-text protection at mutation boundaries as well as in controls. Provider requests include selected editable text only, never artwork, suggestions or recipient rows. AI cannot unlock; manual inspector unlocking is reviewed and restricted to text layers.
- Preserve sourceBox anchors when moving/resizing original text. Erase original ink first, then paint replacement layers. Clip replacement rendering away from protected geometry. Native template baseline offsets and CSV overlay substitutions must be preserved in previews and exports.
- History has no fixed session limit; snapshots share unchanged artwork references. Rollback preserves the redo path, and a new edit from an earlier state creates a new branch.
- Font confidence is a similarity score, not a probability of exact raster font identification. Exclude unsupported script/decorative candidates, use explicit reference text or the selected original style, and preserve colour/weight/slant/spacing/opacity/effects. Cold font/image loading and remote model time are outside warm local timing targets.

- Style matching must use TypographyFingerprintEngine's actual reference pixels or shared-painter rendering. Do not use font-family/script labels as a fallback ranking. All font candidates must pass declared Unicode coverage before being scored.
- Preserve fingerprint uncertainties: opaque-paper color/opacity are not uniquely separable, apparent ink gaps are not CSS tracking, and curved handwritten baselines may be irreproducible. Display quality-adjusted similarity rather than a font-identity probability.
- Candidate refinement must be non-degrading and use the export painter. Cache only completed valid analysis, cancel stale work, and reduce final confidence when target geometry forces scaled typography. Keep wordSpacing, kerning, slantAngle and baselineShift consistent across preview and export.
